# Stock Portfolio API

A RESTful API for tracking stock purchases and sales with user authentication.

## 🚀 Features (In Development)

- User authentication with OAuth2
- Track stock purchases and sales
- Calculate profits/losses per stock and total portfolio
- MySQL database for data persistence

## 🛠️ Technologies

- Python 3.11+
- FastAPI
- MySQL
- SQLAlchemy
- OAuth2 with JWT
